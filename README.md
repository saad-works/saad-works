### 🌍 Open source

I contribute to open-source tools I use and learn from, mostly bug fixes, small features and test coverage:

- **[libredb-studio](https://github.com/libredb/libredb-studio)**: an open-source SQL IDE for the browser. My work there is around the database providers, schema tooling and the MCP layer.
- **[SharpLsp](https://github.com/Nimblesite/SharpLsp)**: a .NET language server for C# and F#. I mostly work on Windows process handling and CI.
